Privacy Policy

Last updated: 28 October 2026

Sconti Otomasyon ("the tool") is the private publishing tool of the YouTube channel Sconti Offerte IT. It is used only by the channel owner.

Which Google data the tool uses

With the channel owner's permission (Google OAuth), the tool uses YouTube API Services to:

  • upload videos, thumbnails and video details (title, description, tags, playlists) to the channel owner's own channel;
  • read the channel's own statistics (views, watch time, impressions, click-through rate) with the YouTube Analytics and YouTube Reporting APIs.

How the data is stored

The OAuth access token and the statistics are stored only on the channel owner's own computer. No data is stored on external servers by the tool.

Sharing

The tool does not sell, share or transfer any Google user data to third parties, and does not use it for advertising. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access

Access can be revoked at any time on the Google account permissions page. Locally stored data is deleted by removing the tool's token file.
